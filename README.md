# IM OpenCV Project

## Descripción

IM OpenCV Project es un proyecto desarrollado en Python y OpenCV para la detección, análisis y medición de objetos a partir de imágenes, utilizando un folio A4 como referencia de escala.

El proyecto está dividido en dos versiones:

- **RulerBase:** aplicación de escritorio para la detección del folio A4 y la medición de objetos.
- **RulerWeb:** ampliación del proyecto original mediante una interfaz web que permite realizar mediciones y gestionar los resultados.
